## Honest product description

Headloom is an AI head-replacement product for fashion catalogue and campaign teams. A user selects an approved identity and a target image, generates a matching result, reviews lighting, hair, occlusion, and composition, then exports approved files. The product is being developed for repeat catalogue workflows rather than individual image editing.

## Google Cloud use case

Headloom plans to use Google Cloud for secure asset storage, queued GPU inference, job metadata, access control, audit records, and review delivery. The first milestone is a controlled pilot workflow. Later milestones add batch processing, organisation-level workspaces, and usage tracking.
